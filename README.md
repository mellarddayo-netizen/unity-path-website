# Unity Path Website

Static website for **UNITY PATH RECOVERY AND COLLECTION SERVICES OPC**.

## Deploy to GitHub Pages

1. Create a GitHub repository named `unity-path-website`.
2. Upload `index.html`, `style.css`, and this README.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Add the custom domain `unitypathrecovery.com` in the Pages settings.

## Important DNS note

Your existing Google Workspace MX record must remain unchanged. The website DNS records can be configured separately.
